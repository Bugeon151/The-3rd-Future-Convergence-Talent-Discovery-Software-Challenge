# LIMITATIONS — 솔직한 한계

경진대회 수준의 "가짜 완벽"을 지양하기 위해, 우리가 스스로 인정하는 한계를 기록합니다.

## 기술적 한계
1. **2D 지면 가정** — 카메라는 평면에 수직으로 보고 있으며, 객체 높이·자세·2D 속도 이상의
   정보는 사용하지 않음. 계단/경사/사각지대 미포함.
2. **확률 보정 미완** — `collision_probability`는 상대적으로 타당한(relative) 목적함수이나,
   절대 교정(calibration) 데이터로 검증되지 않음. 정성적 보정치로 명시.
3. **단일 카메라** — 전방위 범위 불가. 멀티 카메라 병합은 미구현(확장항).
4. **시뮬레이션 우선 검증** — 실제 로봇/현장실증은 수행되지 않았으며, 시나리오는 2D 등속
   근사. 감지 노이즈의 영향도 단위테스트의 밖.
5. **추적 ID 스위치** — 드물게 보행자 간 ID 교체 시 위험 패킷이 일시 분리될 수 있음
   (외부 트래커 ByteTrack 연동 옵션 있음).
6. **사이드채널 검증 지연** — PREVENTED 판정은 위험 하락 프레임 5회(≈0.5s) 후 결정 → 실시간
   알림 자체가 아니라 **후측정(측정계)** 용도.

## 안전/윤리 경계
- **예방 시스템**: 경고·추천·제한 운용이며, 자율 급제동/강제 제어는 시뮬레이션 한정.
- **LLM 무사용 정책**: 안전 판단 경로에 LLM/클라우드 없음. 규칙은 토큰 등 외부 의존 없음.
- **프라이버시**: 얼굴 모자이크는 처리 파이프라인 초입에 적용하지만, 원본 저장 정책은
  배치하는 조직의 준거를 따라야 함.

## 측정 한계 (평가)
- recall/lead 는 GT 접촉구간 기준 — "실제 사고 기록"이 아니라 **합성 GT** 기준
- 거짓경보는 "위험하게 판단한 프레임 수"로 정의 (별도 단위는 사후 카운팅)
- 성능 벤치마크는 학습된 YOLOv8n + RTX 5070 환경 기준
